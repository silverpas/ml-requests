# ML requests

The front door for new machine learning use cases.

Have an idea? Open an issue with the **ML project request** form. The platform
lead qualifies it and answers: approved, deferred or declined. Approved
requests get an Azure setup and a project repo from the template.

The form and the process documents arrive in milestone 6.
See [AGENTS.md](AGENTS.md) for the workflow, labels and rules.
